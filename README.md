## 🎨 Design

Inspired by the Cartoon Network classic **Dexter's Laboratory**:

- 🔴 Bold red / deep navy / black palette
- 🖥️ CRT scanline overlay
- 🔤 `Orbitron` (headings) + `Share Tech Mono` (body)
- 👥 Silhouetted scientists running across the bottom of the screen, each carrying a glowing flask
- ✨ Animated: leg cycles, flask pulse, dial needles, ticker tape, glitch effects
